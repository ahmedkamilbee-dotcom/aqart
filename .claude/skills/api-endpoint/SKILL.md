# FastAPI endpoint: $ARGUMENTS

1. شوف endpoints مشابهة بـ `backend/server.py` أو `backend/leads.py` وانسخ نمطها (المصادقة، التعامل مع قاعدة البيانات، الأخطاء).
2. نماذج الطلب والرد بـ `backend/models.py` (Pydantic)، ولا ترجع حقول ما يحتاجها العميل.
3. الصلاحيات:
   - الوكيل: صفوفه فقط (فلتر بمعرّف المستخدم من التوكن، مو من الطلب).
   - المدير: حسب دوره.
   - العام (روابط المشاركة): بدون بيانات المالك أبداً، ورقم الوكيل فقط إذا مفعّل.
4. رسائل الخطأ للمستخدم بالعربي، وبدون تفاصيل داخلية.
5. تحقق: `python -m py_compile backend/*.py`. إذا الاختبارات ممكنة، أضف حالة بـ `backend/tests/`.
6. اذكر بالتقرير الـ endpoint الجديد وشكل الطلب والرد حتى يستخدمه `frontend-dev`.
