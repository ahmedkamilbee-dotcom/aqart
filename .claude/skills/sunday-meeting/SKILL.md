# اجتماع الأحد

## 1. حضّر أرقام الأسبوع
```bash
git log --since="7 days ago" --pretty="- %h %s" 
git log --since="7 days ago" --shortstat | grep -E "files? changed" | wc -l
node hq/hq.mjs list
```
واقرأ أحداث آخر 7 أيام من `hq/activity.json` والموجزات بـ `hq/briefs/`.

## 2. تقارير الأقسام (بالتوازي، بنفس الرسالة)
- `product-manager`: شنو انجز مقابل أولويات الأسبوع الماضي، وشنو يقترح للأسبوع الجاي (3-5 مهام مرتبة).
- `data-analyst`: المؤشرات المتاحة من الكود والبيانات، بدون اختراع أرقام.
- `security-auditor`: مراجعة سريعة لتغييرات الأسبوع (`git diff HEAD@{7.days.ago}` أو أقرب commit).
- `marketing-lead`: خطة محتوى الأسبوع الجاي (3 منشورات).

## 3. القرارات
- اختار **3-5 أولويات** للأسبوع، كل وحدة لموظف: `node hq/hq.mjs assign <id> "<المهمة>"`.
- مكافآت: موظف الأسبوع (+30 XP)، وأي مساهمة مميزة (+10 إلى +20):
  `node hq/hq.mjs bonus <id> <xp> "<السبب>"`
- الترقيات تصير تلقائياً من الـ XP (شوف `hq/LEVELS.md`).

## 4. المحضر
احفظه في `hq/meetings/YYYY-MM-DD.md`:

```markdown
# 📅 اجتماع الأحد: <التاريخ>

## الأسبوع بالأرقام
## تقارير الأقسام
## القرارات وأولويات الأسبوع الجاي
| # | المهمة | المسؤول | معيار الإنجاز |
## المكافآت والترقيات
## أمور تحتاج قرار صاحب الشركة
```

ثم `node hq/hq.mjs note "اجتماع الأحد: hq/meetings/<التاريخ>.md"`، و commit للمحضر واللوحة، واعرض الملخص للمستخدم.
