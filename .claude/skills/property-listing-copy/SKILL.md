# نص تسويقي: $ARGUMENTS

اكتب 3 نسخ:
1. **إعلان عقار / وصف** (60-90 كلمة): النوع، المحافظة والمنطقة، المساحة، الغرف، السعر، أهم ميزة. عربي فصيح مبسّط.
2. **منشور إنستغرام/فيسبوك**: سطر أول يجذب، نقاط قصيرة بإيموجي قليل، دعوة واضحة (راسلنا واتساب)، و5-8 هاشتاگات عراقية (#عقارات_بغداد ...).
3. **رسالة واتساب** للزبون أو المكتب: قصيرة، لهجة عراقية مهذبة، جاهزة للنسخ.

القواعد:
- لا تذكر اسم المالك أو رقمه.
- لا تبالغ ولا تخترع مواصفات غير مذكورة.
- السعر بالدينار أو الدولار حسب المعطى، ولا تحوّل بدون طلب.
