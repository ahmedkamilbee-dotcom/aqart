# توظيف موظف جديد: $ARGUMENTS

1. تأكد ماكو موظف بـ `.claude/agents/` يغطي نفس الدور. إذا موجود، اقترح توسيع وصفه بدل التوظيف.
2. أنشئ `.claude/agents/<id>.md` على نفس قالب الموظفين الحاليين (اقرأ `db-engineer.md` كمثال):
   - frontmatter: `name`، `description` واضح يبدي بالدور ويگول "استخدمه لـ..."، و`tools` إذا الدور مراجعة فقط (`Read, Grep, Glob, Bash`).
   - اسم عربي، المسؤولية، قواعد الشغل، المهارات، وشكل التقرير.
3. أضفه لـ `hq/roster.json` بمصفوفة `team`:
   `{ "id", "name", "title", "dept", "emoji", "xp": 0, "tasks_done": 0, "status": "idle", "task": "", "queue": [], "skills": [] }`
4. `node hq/hq.mjs note "انضم <الاسم> للفريق: <الدور>"`
5. خبّر المستخدم إن الوكيل الجديد يشتغل من الجلسة الجاية (أو بعد إعادة تحميل الوكلاء).
