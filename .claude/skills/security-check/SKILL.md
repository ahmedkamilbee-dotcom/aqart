# تدقيق أمني

راجع `git diff` (أو الملفات المحددة) مقابل هاي القائمة:

1. **عزل الوكلاء**: كل استعلام يفلتر بمعرّف المستخدم من التوكن. جرّب ذهنياً: وكيل A يطلب عقار أو عميل وكيل B.
2. **الصفحات العامة**: الرد ما يحتوي اسم المالك أو رقمه؛ رقم الوكيل فقط إذا مفعّل؛ الرابط الموقوف يرجّع 404.
3. **الصور**: من الحاوية الخاصة فقط عبر الخادم وبعد التحقق؛ نوع وحجم الملف محدود عند الرفع.
4. **المصادقة**: JWT بسر من البيئة، صلاحية محددة، ونقاط الدخول عليها تحديد محاولات.
5. **CORS و Hosts**: ما يصير `*` بالإنتاج.
6. **SQL**: استعلامات بمعاملات، مو نصوص مركّبة من مدخلات المستخدم.
7. **RLS**: الجداول الجديدة مفعّل عليها RLS.
8. **أسرار**: ماكو مفاتيح أو `.env` بالكود أو الواجهة.

لكل مشكلة: الملف:السطر، السيناريو الواقعي، الخطورة، الإصلاح.
