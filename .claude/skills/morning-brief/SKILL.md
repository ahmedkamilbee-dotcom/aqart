# الموجز الصباحي

## اجمع المعلومات
```bash
git log --since="1 day ago" --pretty="- %h %s (%an)" 
git status -sb
node hq/hq.mjs list
```
- اقرأ آخر 20 حدث من `hq/activity.json`.
- اقرأ آخر ملف بـ `hq/meetings/` (أولويات الأسبوع من اجتماع الأحد).
- عدّ `TODO|FIXME` بالكود (`grep -rn "TODO\|FIXME" backend frontend/src --include=*.py --include=*.js | wc -l`).

## اكتب الموجز
احفظه في `hq/briefs/YYYY-MM-DD.md` (تاريخ بغداد) بهذا الشكل، وبالعربي المختصر:

```markdown
# ☀️ الموجز الصباحي: <التاريخ>

## أمس
- <الإنجازات من git والنشاط، ومنو سواها>

## أولويات اليوم (3 بالأكثر)
1. <المهمة> → <الموظف>
2. ...

## مخاطر أو أشياء معلّقة
- <مهام بالمراجعة من فترة، فحوص فاشلة، أمور تحتاج قرار المستخدم>

## الفريق
- يشتغلون: ... · بالطابور: ... · متاحين: ...
```

لا تخترع إنجازات. إذا ماكو نشاط أمس، اكتب هذا.

## حدّث المكتب
لكل أولوية: `node hq/hq.mjs assign <id> "<المهمة>"`، ثم:
```bash
node hq/hq.mjs note "الموجز الصباحي جاهز: hq/briefs/<التاريخ>.md"
```

اعرض الموجز للمستخدم واسأله إذا يريد تبدي أول أولوية بـ `/hq-task`.
