# المستويات و XP

الترقية تلقائية لما يوصل الموظف للحد (يحسبها `hq/hq.mjs`).

| المستوى | اللقب | من XP |
|---|---|---|
| م1 | متدرّب | 0 |
| م2 | موظف | 100 |
| م3 | موظف أول | 250 |
| م4 | خبير | 500 |
| م5 | قائد | 1000 |

## شلون ينكسب XP
| الإنجاز | XP |
|---|---|
| مهمة صغيرة | 10 |
| مهمة متوسطة | 25 |
| مهمة كبيرة | 50 |
| نجحت المراجعة من أول مرة | +10 |
| المهمة معها اختبارات | +10 |
| مراجِع لگى خطأ حقيقي | 15 لكل خطأ |
| موظف الأسبوع (اجتماع الأحد) | 30 |
| المدير يغلق مهمة كاملة | 5 |

## شنو يعني المستوى
- **م1-م2**: المدير يراجع شغله بالتفصيل، والمراجعة إلزامية.
- **م3**: ياخذ مهام كبيرة لوحده.
- **م4-م5**: يقود مهام متعددة الأقسام، ورأيه يوزن أكثر باجتماع الأحد.
